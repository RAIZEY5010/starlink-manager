# اختصاراتي

تطبيق Android أصلي للـ Text Expansion مكتوب بـ `Kotlin` و`Jetpack Compose`،
وموجّه لإدارة اختصارات النصوص داخل الهاتف عبر خدمة إمكانية الوصول.

## المتطلبات

- Android Studio حديث أو runner يدعم Android SDK Platform 36.
- JDK 17 أو أحدث.
- Gradle Wrapper المرفق (`./gradlew`).
- `GEMINI_API_KEY` اختياري حالياً؛ لا توجد استدعاءات مطلوبة لتشغيل التطبيق.

## البناء

```bash
./gradlew assembleDebug
```

ينتج ملف APK في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

في GitHub Actions يمكن تشغيل workflow باسم **Android Build** يدوياً أو عبر
push إلى `main`. يقوم workflow بإعداد Gradle 9.3.1، وإنشاء debug keystore،
وبناء APK ورفعه كـ artifact باسم `app-debug`.

## التشغيل على الهاتف

1. ثبّت APK على هاتف Android.
2. افتح التطبيق ثم انتقل إلى إعدادات إمكانية الوصول.
3. فعّل خدمة **Text Expander** الخاصة بالتطبيق.
4. في Android 13/14 قد تحتاج إلى فتح معلومات التطبيق واختيار السماح
   بالإعدادات المقيدة قبل تفعيل الخدمة.
5. أضف اختصارًا جديدًا، ثم اكتب الكلمة المفتاحية متبوعة بمسافة داخل أي تطبيق.

## ما تم إصلاحه

- إضافة واجهة أحدث تركز بالكامل على الاختصارات والنصوص المتكررة.
- دعم الوقت العشري داخل الأوسمة مثل `%time+1.5h%` و`%time+1.3h%`.
- إضافة البحث داخل الاختصارات وتثبيت العناصر المهمة في الأعلى.
- إضافة معاينة مباشرة للنص قبل الحفظ.
- تبسيط التطبيق بحذف ميزات الشبكة والخدمات الخلفية غير المتعلقة بالاختصارات.

## ملاحظة عن Replit

هذا مشروع Android وليس تطبيق ويب؛ لذلك لا يمكن عرض واجهته داخل Preview الخاص
بـ Replit أو تشغيل APK داخل حاوية Replit. البناء والتثبيت الفعليان يحتاجان
Android SDK مع محاكي أو هاتف، ويمكن تنفيذ البناء الموثوق عبر GitHub Actions
المرفق.
