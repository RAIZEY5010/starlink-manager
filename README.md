# Text Expander

تطبيق Android أصلي مكتوب بـ Kotlin وJetpack Compose لتحويل الكلمات المختصرة إلى
قوالب نصية كاملة عبر خدمة Android Accessibility، مع واجهة عربية RTL وتجربة إدارة
سريعة للاختصارات.

## المتطلبات

- Android Studio حديث أو runner يدعم Android SDK Platform 36.
- JDK 17.
- Gradle أو Gradle Wrapper المرفق (`./gradlew`).

## البناء

```bash
./gradlew assembleDebug
```

ينتج ملف APK في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

في GitHub Actions يمكن تشغيل workflow باسم **Android Build** يدوياً أو عبر
push إلى `main`. يقوم workflow بإعداد بيئة Android وبناء APK ورفعه كـ artifact
باسم `app-debug`.

## التشغيل على الهاتف

1. ثبّت APK على هاتف Android.
2. فعّل خدمة **Text Expander** من إعدادات إمكانية الوصول.
3. في Android 13/14 قد تحتاج إلى فتح معلومات التطبيق والسماح بالإعدادات المقيدة.
4. أضف اختصاراتك من شاشة التطبيق، ثم جرّب كتابتها متبوعة بمسافة داخل أي حقل نصي.

## الميزات

- متغيرات ذكية مثل `%date%` و`%day%` و`%time%`.
- دعم الساعات العشرية في `%time+1.5h%` و`%time+1.3h%`.
- دعم `%clipboard%` لإدراج آخر نص منسوخ.
- دعم `%cursor%` لتحديد موضع المؤشر بعد التوسيع.
- تصنيفات، بحث سريع، وتثبيت الاختصارات المهمة.
- قائمة استثناء للتطبيقات التي لا تريد تشغيل الموسّع بداخلها.

## ما تم إصلاحه

- إزالة تبويب الشبكة وخدمات الفحص وكل الأذونات والملفات المرتبطة بها.
- تبسيط قاعدة البيانات لتخزين الاختصارات فقط مع التصنيف والتثبيت.
- إنشاء معالج موحد للمتغيرات الذكية والمعاينة المباشرة.
- إعادة تصميم الواجهة ببطاقات Material 3 وألوان أكثر احترافية.
- إضافة شاشة إعدادات تركّز على حالة الخدمة واستثناء التطبيقات.

## ملاحظة عن Replit

هذا مشروع Android وليس تطبيق ويب؛ لذلك لا يمكن عرض واجهته داخل Preview الخاص
بـ Replit أو تشغيل APK داخل الحاوية نفسها. البناء والتثبيت الفعليان يحتاجان
Android SDK مع محاكي أو هاتف، أو تنفيذ workflow البناء عبر GitHub Actions.
