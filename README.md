# مدير Starlink

تطبيق Android أصلي لإدارة أجهزة الشبكة المحلية ومراقبة مدد الاشتراك، مع موسّع
نصوص يعمل عبر خدمة إمكانية الوصول.

## المتطلبات

- Android Studio حديث أو runner يدعم Android SDK Platform 36.
- JDK 17 أو أحدث.
- Gradle Wrapper المرفق (`./gradlew`).
- `GEMINI_API_KEY` اختياري حالياً؛ لا توجد استدعاءات Gemini مطلوبة لتشغيل شاشات
  إدارة الشبكة والاختصارات.

## البناء

```bash
./gradlew assembleDebug
```

ينتج ملف APK في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

في GitHub Actions يمكن تشغيل workflow باسم **Android Build** يدوياً أو عبر
push إلى `main`. يقوم workflow بإعداد Gradle 9.3.1، وإنشاء debug keystore،
وبناء APK ورفعه كـ artifact باسم `app-debug`.

## التشغيل على الهاتف

1. ثبّت APK على هاتف Android متصل بشبكة Wi-Fi.
2. امنح إذن الإشعارات عند الطلب.
3. فعّل خدمة **Text Expander** من إعدادات إمكانية الوصول.
4. في Android 13/14 قد تحتاج إلى فتح معلومات التطبيق واختيار السماح
   بالإعدادات المقيدة قبل تفعيل الخدمة.
5. من شاشة الشبكة أضف الأجهزة يدوياً أو شغّل الفحص. قد تمنع بعض أجهزة
   التوجيه فحص ping؛ في هذه الحالة استخدم عنوان IP يدوياً.

## ما تم إصلاحه

- إضافة Gradle Wrapper متوافق مع Android Gradle Plugin المستخدم.
- منع موسّع النصوص من الاستبدال قبل كتابة مسافة أو سطر جديد، ومنع حلقات
  الاستبدال المتكررة.
- توحيد `%date%` إلى `yyyy-MM-dd` ودعم `%time%` و`%time+Nh%`.
- ضمان إكمال تحديث الوقت من أزرار الإشعارات باستخدام `goAsync()`.
- جعل فحص الشبكة محدود التوازي، آمناً عند فشل بعض المضيفين، ويعيد حالة
  الفحص حتى عند حدوث استثناء.
- التحقق من IPv4 عند الإضافة اليدوية.
- طلب إذن الإشعارات على Android 13+ واستخدام ثيم التطبيق فعلياً.
- تصحيح اختبارات اسم التطبيق و`applicationId`.

## ملاحظة عن Replit

هذا مشروع Android وليس تطبيق ويب؛ لذلك لا يمكن عرض واجهته داخل Preview الخاص
بـ Replit أو تشغيل APK داخل حاوية Replit. البناء والتثبيت الفعليان يحتاجان
Android SDK مع محاكي أو هاتف، ويمكن تنفيذ البناء الموثوق عبر GitHub Actions
المرفق.
